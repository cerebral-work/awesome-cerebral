## Biological Memory & Consolidation

- [reverie](https://cerebral.work/reverie) — Biological memory daemon for autonomous coding agents: observation writes, typed-then-distilled retrieval, and sleep-phase consolidation.
- **Dual-Store Consolidation** — Translating episodic interaction buffers into durable semantic graphs across sessions.
- **Janus Datalog & Cicatrix** — Regression-memory and convention-drift tracking frameworks.

## Distributed Mesh & Multi-Agent Coordination

- [meshctl](https://cerebral.work/meshctl) — Multi-agent orchestration with file-level locking and coord-protocol messaging.
- **Cortex Mesh** — Role-addressed, peer-to-peer agent mesh with backpressure and inbox acknowledgment semantics.
- **Coord Protocol** — Distributed systems substrate replacing ad-hoc terminal multiplexer scripts.

## Cognitive Architectures & Agent Harnesses

- **Hash-Anchored Edits** — Verification-first modifications using cryptographic line-anchors to avoid hallucinated overwrites.
- **Bounded Specialists** — Modular agent decomposition where lightweight models probe and verify while capable models build and critique.
